# Codemap – mapa kódu pro agenty

`scripts/codemap.py` vypíše kompaktní, vždy aktuální mapu kódu: soubory, první řádek docstringu/JSDoc,
veřejné symboly se signaturou a interní importy. Agent se nejdřív zorientuje v mapě a celé soubory čte
až cíleně. Jediný zdroj pravdy je kód: žádné LLM, žádná síť, žádné časové razítko – dva běhy nad stejným
stromem dají byte-identický výstup.

## Příklady

```bash
pnpm codemap modules/wine                       # mapa jednoho modulu (= python3 scripts/codemap.py …)
pnpm codemap custom_components/homebrain/energy --deps-only
pnpm codemap --rdeps custom_components/homebrain/const.py            # kdo soubor importuje
pnpm codemap --rdeps packages/signals/src/index.ts --depth 2          # tranzitivně
pnpm codemap --missing-docs modules/agents      # chybějící docstringy/JSDoc + souhrn po modulech
pnpm codemap --format json --max-chars 20000    # strojově, s limitem velikosti
pnpm codemap --include-tests tests/python/test_codemap.py
```

`pnpm codemap` běží z kořene repa, cesty proto zadávejte od kořene.

## Formát

```
custom_components/homebrain/x/advisor.py — Compute advice from prices.
  deps: custom_components/homebrain/x/store.py, custom_components/homebrain/const.py
  class Advisor — Holds state for one tariff.
    advise(self, now: datetime) -> Advice — Return the advice for now.
```

- Za `—` je první řádek docstringu/JSDoc; chybějící dokumentace = `—` bez textu (nic se nedomýšlí).
- Python (`ast`): module docstring, veřejné top-level třídy (+ veřejné metody) a funkce se signaturou.
- TS/TSX/JS (`scripts/codemap-ts.mjs`, `ts.createSourceFile` po souborech, bez type-checku): file-level
  JSDoc, exporty (function/class/const/interface/type/enum, re-exporty), signatury zkrácené na 140 znaků.
- `deps`: jen interní importy jako cesty od kořene repa – relativní, `custom_components.homebrain…`
  a workspace balíčky (`@homebrain/ui` → `packages/ui`, podle `name` v `package.json`).
- `--max-chars N` ořízne po celých souborech a na konci napíše, kolik bloků a znaků zbylo
  (v JSON klíč `truncated`).

## Rozsah a omezení

- Jen soubory z `git ls-files` v `custom_components/ modules/ packages/ apps/ scripts/`; bez `node_modules`,
  `dist`, `*.d.ts` a generovaných souborů (`*.gen.*`, `*.generated.*`, hlavička „Generated by…“).
  Testy (`tests/`, `*.test.*`, `*.spec.*`) jen s `--include-tests`.
- `_privátní` symboly se nevypisují. Import balíčku (`@homebrain/ui`) se v `--rdeps` počítá jako import
  jeho vstupu (`src/index.ts[x]`), ne každého souboru uvnitř.
- Dynamické importy s nekonstantní cestou a `require()` se nesledují. TS část potřebuje `node`
  a nainstalované `node_modules` (`pnpm install`).
- Celé repo trvá na sdíleném hostu ~3 s a má ~480 k znaků – pro agenty vždy zužte cestu.
